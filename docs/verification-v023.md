# v0.2.3 — manual start, statuses, optional comparison, complete monitor removal

User-approved bounded UI change and UAC-per-Start device lifecycle, 2026-10-18.

- The normal entry point opens idle. Start explicitly acquires the display and starts video/audio. Hidden smoke diagnostics explicitly opt into automatic start.
- English Video, Audio, Display and optional Comparison statuses. Stop clears both previews and resets frame counters shown in the UI.
- Before / After defaults off. Before is a small clipped scRGB-to-sRGB visualization without tone mapping; After is the processed SDR stream. It does not claim to reproduce Discord's private conversion. A worker-owned raw session starts only when enabled, samples at up to5FPS, closes when disabled/minimized/stopped, and reports comparison failures independently of SDR capture.
- Each Start asks for UAC for a temporary helper, while capture/audio/UI remain unelevated. The helper validates the fixed dedicated root-device identity and pinned package marker before using pnputil to enable/disable that adapter. The installed signed driver package remains available for the next session; no permanent service, scheduled task, reboot or physical-display change.
- Parent PID and creation time are checked. Named events communicate setup failure separately from successful cleanup. The parent releases the display mutex before signaling Stop; the helper acquires it before any removal and holds it through transient PnP retries. If a newer session owns the mutex, deferred cleanup stays alive until ownership is available, covering a canceled UAC in the newer session without disconnecting it.
