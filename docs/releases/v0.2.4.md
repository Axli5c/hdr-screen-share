# HDR Screen Share v0.2.4

[English](#english) · [Русский](#русский)

## English

HDR Screen Share converts an HDR monitor to SDR for Discord while keeping HDR enabled locally. Choose the source monitor, start processing manually and share either the separate application window or a virtual screen.

Optional Before / After previews show the source and processed image. The application audio relay excludes desktop Discord and the app's own output; microphone devices are not opened.

Preview release for Windows 11 x64. The app interface is English. Output supports up to 3840×2160 or 2160×3840 with a 60 FPS target; actual HDR 4K60 streaming has not yet been validated.

| Mode | Discord source | Additional setup |
| --- | --- | --- |
| Application window | **HDR Screen Share** | VB-CABLE for filtered application audio; no virtual monitor or session UAC. |
| Virtual screen | The screen number shown by the app | Signed virtual display driver; UAC at each Start. Discord handles system audio; VB-CABLE is not needed. |

### Install with Setup

1. Open [release v0.2.4](https://github.com/Axli5c/hdr-screen-share/releases/tag/v0.2.4) and download **HDRScreenShare-Setup-v0.2.4-windows-x64.exe** under **Assets**.
2. Run Setup and choose the installation folder. The interface is English.
3. On **Select Components**, keep **HDR Screen Share** selected. Python and all application libraries are included.
4. Tick **Virtual Display Driver** for **Virtual screen**, or **VB-CABLE by VB-Audio** for sound in **Application window**. Select both if you use both modes. Both optional checkboxes are off by default.
5. Click **Install**. Selected drivers are downloaded from their publishers, checked using pinned SHA-256 hashes and digital signatures, then installed after Windows UAC approval. Working installed components are skipped. Internet access is needed only for missing selected drivers.
6. Read the result on the last page. If VB-CABLE was installed, restart Windows manually before using its sound. Keep headphones as the default Windows output and your microphone as the input. Setup does not restart Windows automatically.
7. Open **HDR Screen Share** from Start, select a monitor and press **Start** when ready.

The application installs for the current user; only driver setup requires administrator approval. Driver setup errors do not remove the application. The last page shows which component failed; details are saved in `setup-result.txt` in the application folder. Run Setup again and select the missing component to retry.

Installer checks: [verification results](https://github.com/Axli5c/hdr-screen-share/blob/main/docs/verification-installer.md). Installation of missing drivers on a clean Windows system has not yet been validated.

VB-CABLE is donationware by [VB-Audio](https://vb-audio.com/Cable/); support the author if you find it useful. [Vendor licensing](https://vb-audio.com/Services/licensing.htm) applies separately from this project's MIT license.

Uninstall HDR Screen Share through **Windows Settings → Apps → Installed apps**. Shared drivers are retained. The virtual display stays disabled while the application is stopped. VB-CABLE can be removed through its original vendor installer.

### Portable ZIP

1. Open [release v0.2.4](https://github.com/Axli5c/hdr-screen-share/releases/tag/v0.2.4).
2. Under **Assets**, download **HDRScreenShare-v0.2.4-windows-x64.zip**. The **Source code** archives are for development and do not contain the ready-to-run program.
3. In File Explorer, right-click the downloaded ZIP and select **Extract All**. Choose a folder you can write to, such as Documents or a folder for portable applications.
4. Open the extracted **HDRScreenShare** folder and run **HDRScreenShare.exe**. Run the extracted copy, not the EXE inside the ZIP.
5. Keep the entire folder together. `_internal` contains the bundled runtime, libraries and native modules; copying only the EXE is not enough.
6. Choose a sharing mode and complete its setup below. The application opens idle and starts processing only after **Start**.

For normal use, do not install Python, run pip, or build the source code. The interface is in English. Use the Setup above if you want optional drivers installed automatically.

Use `SHA256SUMS.txt` from the same release to verify the ZIP:

```powershell
Get-FileHash .\HDRScreenShare-v0.2.4-windows-x64.zip -Algorithm SHA256
```

### Requirements and additional components

| Component | Do you need to install it separately? |
| --- | --- |
| Windows 11 x64 | Required; this is the tested platform. macOS, Linux, Windows ARM64 and 32-bit Windows builds are not provided. |
| HDR monitor and graphics driver | Enable HDR for the source monitor in Windows. The GPU/driver must support Direct3D 11. Use the normal driver for your graphics card. |
| Desktop Discord | Install or update it from the [official Discord download page](https://discord.com/download). Use its desktop application for filtered Discord-audio exclusion. |
| Python, PySide6/Qt, NumPy, hdrcapture | No. These are included in the portable folder. |
| Native audio/video modules and C/C++ runtime files | Included in the portable folder. Keep `_internal` intact. |
| Direct3D and WASAPI | Windows components; no separate package is needed. |
| VB-CABLE | Only for filtered sound in **Application window**. Select it in Setup, or install manually below. Video can run without it, with an Audio unavailable status. |
| Virtual display driver | Only for **Virtual screen**. Select it in Setup, or install through the application's **Devices** dialog below. |

MSVC Build Tools, a Windows SDK and development Python packages are needed only when building from source, not when using the release ZIP.

If Windows reports a missing `MSVCP140.dll` or `VCRUNTIME140.dll` even with the full folder extracted, install or repair the official [Microsoft Visual C++ v14 Redistributable, x64](https://aka.ms/vc14/vc_redist.x64.exe) and reopen the app. See [Microsoft's runtime documentation](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist). This is a recovery step, not a Python-library installation.

### One-time setup

Install only the component needed by the mode you intend to use. Both extra drivers are needed only if you plan to use both modes with audio.

#### Application window: install VB-CABLE for audio

1. Open HDR Screen Share and choose **Application window**.
2. Open **Devices** and click **Get VB-CABLE (window mode)**. It opens the [official VB-Audio download page](https://vb-audio.com/Cable/); the app does not silently install the audio driver.
3. Download the Windows **VB-CABLE** package and extract all its files. Use the standard VB-CABLE package, not the separate A+B or C+D products.
4. Right-click **VBCABLE_Setup_x64.exe**, choose **Run as administrator**, approve UAC and click **Install Driver** in the vendor installer.
5. Restart Windows after installation, as instructed by [VB-Audio](https://vb-audio.com/Cable/). HDR Screen Share does not restart Windows for you.
6. In Windows sound settings, keep your headphones or speakers as the default playback device. Do not make **CABLE Input** the default system output. The installed cable exposes **CABLE Input** as a playback endpoint and **CABLE Output** as a recording endpoint; the app finds the playback endpoint automatically.
7. Reopen HDR Screen Share, select **Application window**, then **Devices → Refresh**. With a supported setup the dialog shows **Devices ready**.
8. Select your source monitor and click **Start**. Normal window capture does not request UAC and does not create a virtual monitor.
9. In Discord, share **HDR Screen Share** and enable application audio. Leave Discord's microphone input at your normal setting; the cable is used for the stream's application audio, not as your microphone.

If VB-CABLE is already installed and recognized by Devices, skip the download and installation. Without VB-CABLE, application-mode video can still run, but the filtered audio relay is unavailable.

#### Virtual screen: install the display driver

1. Open HDR Screen Share and choose **Virtual screen**.
2. Open **Devices** and click **Install virtual display**. Internet access is needed for this one-time download.
3. The app downloads its supported signed driver package, checks its archive hash and publisher signatures, then requests UAC to install the dedicated adapter. Wait for completion; do not close the setup dialog while it is downloading or installing.
4. Click **Refresh** and check for **Devices ready**. If Windows explicitly requests a restart, restart manually before using the mode. The program never restarts the PC automatically.
5. Close Devices, choose the source monitor and click **Start**. Approve the separate UAC request that enables the adapter for this session. This request occurs at each screen-mode Start, not only during installation.
6. In Discord, share the screen number shown by the app and enable Discord's system-audio option. VB-CABLE is not required for this mode.
7. Use **Stop** or close the app when finished. The virtual monitor is removed from display enumeration; its driver stays installed for the next Start.

If the dedicated driver is already installed, Devices recognizes it even while its adapter is disabled; reinstalling it for each session is unnecessary. The installer does not adopt or overwrite a different existing Virtual Display Driver installation. Use Application window mode or resolve that existing installation before setting up this mode.

97 automated tests pass. Local packaged captures, a changing synthetic 4K window, mode switching and virtual-display cleanup were checked. Discord's actual picker/viewer delivery, end-to-end audio/video synchronization and HDR 4K60 remain unverified. Before / After is optional; Before is an unmapped-preview illustration, not an exact reproduction of Discord's conversion.

## Русский

HDR Screen Share преобразует изображение HDR-монитора в SDR для трансляции через Discord, сохраняя HDR включённым на локальном экране. Выбери исходный монитор, запусти обработку вручную и транслируй отдельное окно приложения или виртуальный экран.

По желанию можно включить сравнение Before / After. Отфильтрованный звук приложений исключает настольный Discord и собственный вывод программы; микрофон не захватывается.

Предварительная версия для Windows 11 x64. Интерфейс приложения — английский. Поддерживается выход до 3840×2160 или 2160×3840 с целевой частотой 60 FPS; реальная трансляция HDR 4K60 пока не подтверждена.

| Режим | Источник в Discord | Дополнительная настройка |
| --- | --- | --- |
| Application window | **HDR Screen Share** | VB-CABLE для отфильтрованного звука приложений; без виртуального монитора и UAC при запуске сессии. |
| Virtual screen | Номер экрана, показанный программой | Подписанный драйвер виртуального дисплея; UAC при каждом Start. Системный звук передаёт Discord; VB-CABLE не нужен. |

### Установка через Setup

1. Открой [релиз v0.2.4](https://github.com/Axli5c/hdr-screen-share/releases/tag/v0.2.4) и в разделе **Assets** скачай **HDRScreenShare-Setup-v0.2.4-windows-x64.exe**.
2. Запусти Setup и выбери папку установки. Интерфейс установщика — английский.
3. На странице **Select Components** оставь **HDR Screen Share**. Python и все библиотеки приложения уже включены.
4. Отметь **Virtual Display Driver** для режима **Virtual screen** или **VB-CABLE by VB-Audio** для звука в **Application window**. Если нужны оба режима, отметь оба компонента. По умолчанию обе дополнительные галочки выключены.
5. Нажми **Install**. Выбранные драйверы скачаются с сайтов авторов, пройдут проверку закреплённых SHA-256 и цифровых подписей, затем установятся после подтверждения Windows UAC. Рабочие установленные компоненты будут пропущены. Интернет нужен только для отсутствующих выбранных драйверов.
6. Прочитай результат на последней странице. После новой установки VB-CABLE перезагрузи Windows вручную перед использованием звука. Оставь наушники выводом Windows по умолчанию, а микрофон — входом. Автоматической перезагрузки нет.
7. Открой **HDR Screen Share** из меню Пуск, выбери монитор и нажми **Start**, когда будешь готов.

Программа устанавливается для текущего пользователя; права администратора нужны только для драйверов. При ошибке драйвера приложение остаётся установленным. Последняя страница показывает проблемный компонент, подробности сохраняются в `setup-result.txt` в папке программы. Для повторной попытки запусти Setup и отметь недостающий компонент.

Проверки установщика: [результаты](https://github.com/Axli5c/hdr-screen-share/blob/main/docs/verification-installer.md). Установка отсутствующих драйверов на чистой Windows пока не подтверждена.

VB-CABLE — Donationware от [VB-Audio](https://vb-audio.com/Cable/): поддержи автора, если программа полезна. Его [условия лицензирования](https://vb-audio.com/Services/licensing.htm) действуют отдельно от MIT-лицензии проекта.

Удаление HDR Screen Share: **Параметры Windows → Приложения → Установленные приложения**. Общие драйверы сохраняются. Виртуальный дисплей остаётся отключённым, пока приложение остановлено. VB-CABLE удаляется через оригинальный установщик автора.

### Переносимый ZIP

1. Открой [релиз v0.2.4](https://github.com/Axli5c/hdr-screen-share/releases/tag/v0.2.4).
2. В разделе **Assets** скачай **HDRScreenShare-v0.2.4-windows-x64.zip**. Архивы **Source code** содержат исходники для разработки, а не готовую программу.
3. В Проводнике нажми правой кнопкой на ZIP и выбери **Извлечь всё**. Распакуй его в доступную для записи папку, например в Документы или каталог переносимых программ.
4. Открой получившуюся папку **HDRScreenShare** и запусти **HDRScreenShare.exe**. Запускай распакованную копию, а не EXE внутри ZIP.
5. Сохраняй всю папку целиком. В `_internal` находятся среда выполнения, библиотеки и нативные модули; одного EXE недостаточно.
6. Выбери режим и выполни его первичную настройку ниже. До нажатия **Start** обработка не запускается.

Для обычного использования не нужно устанавливать Python, выполнять pip или собирать исходники. Интерфейс программы — английский. Для автоматической установки дополнительных драйверов используй Setup выше.

Для проверки архива сравни результат следующей команды со значением в **SHA256SUMS.txt** из того же релиза:

```powershell
Get-FileHash .\HDRScreenShare-v0.2.4-windows-x64.zip -Algorithm SHA256
```

### Требования

| Компонент | Нужно ли устанавливать отдельно? |
| --- | --- |
| Windows 11 x64 | Обязательна; на ней выполнялись проверки. Сборки для macOS, Linux, Windows ARM64 и 32-битной Windows не предоставляются. |
| HDR-монитор и драйвер видеокарты | Включи HDR для исходного монитора в Windows. Видеокарта и её драйвер должны поддерживать Direct3D 11. Используется обычный драйвер твоей видеокарты. |
| Настольный Discord | Устанавливается и обновляется отдельно с [официального сайта Discord](https://discord.com/download). Для исключения звука Discord из отфильтрованного микса используй настольное приложение. |
| Python, PySide6/Qt, NumPy, hdrcapture | Нет. Они входят в переносимую сборку. |

MSVC Build Tools, Windows SDK и Python-пакеты для разработки нужны только для сборки из исходников, а не для запуска готового ZIP.

Если после полной распаковки Windows сообщает об отсутствии `MSVCP140.dll` или `VCRUNTIME140.dll`, установи или восстанови официальный [Microsoft Visual C++ v14 Redistributable, x64](https://aka.ms/vc14/vc_redist.x64.exe) и снова открой программу. Подробнее — в [документации Microsoft](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist). Это способ восстановления среды выполнения, а не установка Python-библиотек.

### Звук и первичная настройка

Устанавливай только компонент выбранного режима. Оба дополнительных драйвера понадобятся, только если ты собираешься использовать оба режима со звуком.

#### Application window: установка VB-CABLE для звука

1. Открой HDR Screen Share и выбери **Application window**.
2. Нажми **Devices → Get VB-CABLE (window mode)**. Откроется [официальная страница VB-Audio](https://vb-audio.com/Cable/); приложение не устанавливает аудиодрайвер автоматически.
3. Скачай Windows-пакет **VB-CABLE** и распакуй все его файлы. Нужен обычный VB-CABLE, а не отдельные продукты A+B или C+D.
4. Нажми правой кнопкой на **VBCABLE_Setup_x64.exe**, выбери **Запуск от имени администратора**, подтверди UAC и нажми **Install Driver** в установщике производителя.
5. Перезагрузи Windows после установки — это указано в [инструкции VB-Audio](https://vb-audio.com/Cable/). HDR Screen Share сам компьютер не перезагружает.
6. В параметрах звука Windows оставь наушники или колонки устройством воспроизведения по умолчанию. Не назначай **CABLE Input** системным выходом по умолчанию. После установки **CABLE Input** появляется среди устройств воспроизведения, а **CABLE Output** — среди устройств записи; программа сама находит нужный выход кабеля.
7. Снова открой HDR Screen Share, выбери **Application window**, затем **Devices → Refresh**. При подходящей конфигурации появится **Devices ready**.
8. Выбери исходный монитор и нажми **Start**. Обычный запуск этого режима не запрашивает UAC и не создаёт виртуальный экран.
9. В Discord выбери для трансляции **HDR Screen Share** и включи звук приложения. Настройку микрофона Discord оставь обычной: кабель используется для звука трансляции, а не вместо твоего микрофона.

Если VB-CABLE уже установлен и определяется через Devices, повторно скачивать и устанавливать его не нужно. Без VB-CABLE изображение в оконном режиме может работать, но отфильтрованный звук приложения будет недоступен.

#### Virtual screen: установка драйвера дисплея

1. Открой HDR Screen Share и выбери **Virtual screen**.
2. Нажми **Devices → Install virtual display**. Для этой разовой загрузки нужен интернет.
3. Программа скачает поддерживаемый подписанный пакет, проверит хеш архива и подписи издателя, затем запросит UAC для установки выделенного адаптера. Дождись завершения; не закрывай окно настройки во время загрузки или установки.
4. Нажми **Refresh** и проверь статус **Devices ready**. Если Windows явно попросит перезагрузку, выполни её вручную до использования режима. Программа автоматически компьютер не перезагружает.
5. Закрой Devices, выбери исходный монитор и нажми **Start**. Подтверди отдельный запрос UAC на включение адаптера для текущей сессии. Такой запрос появляется при каждом Start в экранном режиме, а не только при установке драйвера.
6. В Discord выбери номер экрана, показанный программой, и включи системный звук. VB-CABLE для этого режима не требуется.
7. После трансляции нажми **Stop** или закрой программу. Виртуальный монитор исчезнет из списка экранов; драйвер останется установленным для следующего запуска.

Если выделенный драйвер уже установлен, Devices определит его даже при отключённом адаптере. Переустанавливать его при каждом запуске не нужно. Установщик не присваивает и не перезаписывает другую существующую установку Virtual Display Driver. В таком случае используй Application window или сначала разберись с прежней установкой драйвера.

Фильтр исключения Discord действует в режиме **Application window**. В режиме **Virtual screen** захват системного звука выполняет сам Discord. Звук вкладки Discord в браузере нельзя надёжно отделить от других звуков того же браузера — для фильтра используйте настольный Discord. Неподдерживаемые системные аудиосессии исключаются из отфильтрованного микса.
