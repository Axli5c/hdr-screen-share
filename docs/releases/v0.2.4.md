# HDR Screen Share v0.2.4

Preview release for Windows 11 x64.

Convert an HDR monitor to SDR for Discord while keeping HDR enabled locally.

## Download and run

1. Download **HDRScreenShare-v0.2.4-windows-x64.zip** from this release.
2. Extract the whole archive.
3. Open **HDRScreenShare/HDRScreenShare.exe**. Keep `_internal` beside the executable.
4. Choose an HDR monitor and a sharing mode, then click **Start**.
5. Select the source shown by the application in Discord and enable the relevant audio option.

Python is not required for the portable build. The archive is a portable folder, not an installer.

## Sharing modes

| Mode | Discord source | Requirements |
| --- | --- | --- |
| Application window | **HDR Screen Share** | No virtual monitor or UAC. VB-CABLE is needed for filtered application audio. |
| Virtual screen | The screen number shown by the app | Signed virtual display driver; UAC at each Start. Audio is captured by Discord. |

Use **Devices** for one-time driver/audio setup. Keep headphones as the Windows default output.

## Included

- Monitor selection and HDR-to-SDR processing.
- Manual Start/Stop and separate video, audio and display statuses.
- Optional Before / After previews.
- Output up to 3840×2160 or 2160×3840; 60 FPS target.
- Filtered application audio that excludes desktop Discord and the application's own output. Microphone devices are not opened.
- Automatic virtual-display removal after Stop, exit or parent-process crash in Virtual screen mode.

## Validation and current limits

97 automated tests pass. Native and packaged application captures were checked locally, including a changing synthetic 4K window. Application mode keeps the virtual adapter disabled; mode switching and cleanup were checked.

Discord's actual picker/viewer delivery, end-to-end audio/video synchronization and HDR 4K60 have not yet been validated. This release is marked as a preview. Before is a clipped visualization of the unmapped HDR signal, not an exact reproduction of Discord's conversion. Desktop Discord exclusion applies to the application audio relay; Virtual screen mode follows Discord's system-audio behavior.

## Русское описание

**HDR Screen Share v0.2.4** — предварительная версия для Windows 11 x64. Преобразует изображение HDR-монитора в SDR для трансляции через Discord, сохраняя HDR включённым на локальном экране. Интерфейс приложения — английский.

### Скачать и запустить

1. Скачай **HDRScreenShare-v0.2.4-windows-x64.zip** из этого релиза.
2. Распакуй архив целиком и запусти **HDRScreenShare/HDRScreenShare.exe**. Папка `_internal` должна оставаться рядом с EXE.
3. Выбери HDR-монитор и режим, затем нажми **Start**.
4. Выбери указанный программой источник в Discord и включи соответствующую передачу звука.

Python для готовой сборки не нужен. Архив содержит переносимую папку, а не установщик.

| Режим | Источник в Discord | Требования |
| --- | --- | --- |
| **Application window** | **HDR Screen Share** | Без виртуального монитора и UAC. Для отфильтрованного звука нужен VB-CABLE. |
| **Virtual screen** | Номер экрана, показанный программой | Подписанный драйвер виртуального дисплея и UAC при Start. Звук захватывает Discord. |

Первичная настройка доступна через **Devices**. Наушники должны оставаться устройством вывода Windows по умолчанию.

### Возможности

- Выбор монитора и преобразование HDR → SDR.
- Ручной запуск и остановка, отдельные статусы видео, звука и экрана.
- Сравнение **Before / After** по желанию.
- Выход до 3840×2160 или 2160×3840; целевая частота — 60 FPS.
- В режиме приложения — звук программ и игр без настольного Discord и собственного вывода программы. Микрофон не захватывается.
- Автоматическое удаление виртуального экрана при Stop, закрытии или сбое программы в режиме Virtual screen.

### Что проверено

Пройдены 97 автоматических тестов, локальные проверки готового EXE и меняющегося синтетического 4К-окна. В оконном режиме виртуальный адаптер остаётся отключённым; переключение режимов и очистка проверены.

Реальное получение трансляции зрителем Discord, синхронизация звука с видео и HDR 4K60 пока не подтверждены. Before иллюстрирует сигнал без тонмаппинга и не повторяет в точности обработку Discord. Фильтр звука Discord действует только в режиме приложения; экранный режим использует поведение системного звука самого Discord.
