# v0.2.4 — application capture without a virtual monitor

User-approved mode separation, 2026-10-18. Application window no longer acquires a DisplayLease, enables a VDD adapter or launches an elevated helper. Virtual screen keeps the existing UAC-controlled display lease and cleanup. Application device setup requires only its audio endpoint, not a virtual display driver.

Investigation: a fully offscreen Qt raster window produced black/stale WGC output. A one-pixel desktop intersection and explicit Qt backing-store painting did not preserve its complete surface. A Direct3D flip-model swap chain did: synthetic3840x2160 WGC capture returned both changing colors while the entire window was outside all physical screen bounds. Implemented a small native video_presenter.dll used only by application mode, with BGRA8 input and SDR Rec.709/gamma2.2 output color space. Oversized sources are downscaled to the existing fit_size limit before GPU upload. Presenter is released on Stop/mode change; rendering failures stop capture/audio and surface an error. Source-only topology is watched in application mode. Previous display-removal notifications are drained during startup when changing modes.
