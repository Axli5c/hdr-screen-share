# HDR Screen Share

[English](README.md) · Русский

Показывай HDR-экран в Discord без пересвеченной картинки. Программа преобразует захват в SDR, сохраняя HDR на твоём мониторе.

**Windows 11 x64 · Preview · MIT**

[Скачать](https://github.com/Axli5c/hdr-screen-share/releases) · [Изменения](CHANGELOG.md) · [Сообщить об ошибке](https://github.com/Axli5c/hdr-screen-share/issues)

## Установка

1. В последнем релизе скачай **HDRScreenShare-Setup-v…-windows-x64.exe** и запусти его.
2. Выбери русский или английский язык установщика. Python и библиотеки уже включены; интерфейс приложения — на английском.
3. При желании отметь драйверы в Setup. Их также можно установить позже из приложения.
4. При запуске откроется **Dependencies**, если нужны установка или настройка:
   - **✓ Ready** — компонент доступен.
   - **✗** — компонент отсутствует: нажми **Install** или **Download / instructions**.
   - **⚠** — требуется настройка, перезагрузка или исправление ошибки.

Проверка выполняется при запуске, возвращении в приложение, в открытом окне Dependencies и по кнопке **Check again**. Галочка появляется после проверки доступности драйвера. Для установки нужны права администратора; автоматическая загрузка требует интернета. Программа не перезагружает компьютер сама.

**Portable:** скачай ZIP, распакуй целиком и запусти `HDRScreenShare.exe`. Папка `_internal` должна оставаться рядом.

## Трансляция

Выбери исходный монитор и режим, нажми **Start**, затем выбери источник в Discord. **Stop** завершает обработку. До Start захват не ведётся.

| Режим | Зависимость | Что выбрать в Discord |
| --- | --- | --- |
| **Virtual screen** | Virtual Display Driver | Экран с номером, указанным в приложении; включи системный звук |
| **Application window** | VB-CABLE для звука | **HDR Screen Share**; включи звук приложения |

Устанавливай только драйвер нужного режима. Отсутствие второго не мешает работе первого. Virtual screen запрашивает UAC при каждом Start; виртуальный экран отключается после Stop или выхода. Application window не создаёт виртуальный монитор.

**Before / After** показывает исходное и преобразованное изображение. Выход — до 4K, целевая частота — 60 FPS; фактическое качество трансляции зависит от компьютера и Discord.

## Ручная установка драйверов

- **VB-CABLE:** открой [сайт VB-Audio](https://vb-audio.com/Cable/), скачай обычный VB-CABLE, распакуй архив и запусти `VBCABLE_Setup_x64.exe` от администратора. Нажми **Install Driver**, затем перезагрузи Windows. Оставь наушники/колонки выводом по умолчанию, а микрофон — входом. VB-CABLE — donationware от VB-Audio.
- **Virtual Display Driver:** скачай `Signed-Driver-v24.12.24-x64.zip` из [поддерживаемого релиза](https://github.com/VirtualDrivers/Virtual-Display-Driver/releases/tag/25.5.2). В **Dependencies** выбери **Install downloaded VDD ZIP…**. Приложение проверит пакет и зарегистрирует свой адаптер. Обычная сторонняя установка VDD эту подготовку не заменяет; существующий чужой адаптер программа не перезаписывает.

После установки нажми **Check again**. Если показано **Restart Windows**, перезагрузи именно Windows, а не только приложение.

## Если что-то не работает

- **Setup не установил драйвер:** открой **Dependencies** и повтори установку или скачай пакет вручную. Ошибка и путь к отчёту показываются в окне.
- **VB-CABLE установлен, но недоступен:** открой **Windows sound settings**, включи CABLE Input и проверь, что вывод по умолчанию — наушники/колонки.
- **Нет картинки в Discord:** нажми Start и заново открой выбор источника. В режиме окна выбирай **HDR Screen Share**, а не **Controls**.
- **Нет звука:** проверь Dependencies и включи передачу звука в Discord. Для исключения голоса Discord из звука приложений используй настольный Discord; вкладку браузера отдельно от других звуков браузера исключить нельзя.

Лог: `%LOCALAPPDATA%/HDRScreenShare/app.log`. Отчёты установки из приложения: `%LOCALAPPDATA%/HDRScreenShare/setup/`. Для обращения об ошибке укажи версию, режим, Windows и текст ошибки.

Это предварительная версия: стабильность 4K60, синхронизация звука и итоговая картинка у зрителя Discord ещё не подтверждены. При обычной работе программа не сохраняет изображение или звук.

## Сборка из исходников

Для разработки нужны Python 3.12 x64, MSVC Build Tools с C++ и Windows SDK. Для Setup — Inno Setup 6.7+.

```powershell
py -3.12 -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements-dev.txt
./build.ps1
./scripts/package-release.ps1
./scripts/build-installer.ps1
```

Приложение: `dist/HDRScreenShare/`. Пакеты: `dist/releases/`. Запуск из исходников: `./run.ps1`. Тесты: `.venv/Scripts/python.exe -m pytest -q`.
