# HDR Screen Share 0.2.4

[English](README.md) · Русский

Программа для преобразования изображения HDR-монитора в SDR при трансляции через Discord. HDR на локальном экране остаётся включённым.

Windows x64 · Python + Direct3D/WASAPI · MIT · Предварительная версия

[Скачать v0.2.4](https://github.com/Axli5c/hdr-screen-share/releases/tag/v0.2.4) · [История версий](CHANGELOG.md) · [Лицензия](LICENSE)

## Что умеет

- Выбор монитора для захвата и преобразования HDR → SDR.
- Два режима: отдельное окно приложения или виртуальный экран.
- Ручной запуск кнопкой **Start** и остановка кнопкой **Stop**.
- Отдельные статусы видео, звука и экрана.
- Сравнение изображения **Before / After**, включаемое по желанию.
- Выходное разрешение до 3840×2160, в портретной ориентации — до 2160×3840. Целевая частота — 60 FPS.
- В режиме приложения — звук программ и игр с исключением настольного Discord и собственного звука программы. Микрофон не захватывается.

Интерфейс приложения — на английском языке.

## Скачать и запустить

1. Открой [релиз v0.2.4](https://github.com/Axli5c/hdr-screen-share/releases/tag/v0.2.4).
2. Скачай **HDRScreenShare-v0.2.4-windows-x64.zip**.
3. Распакуй архив целиком.
4. Запусти **HDRScreenShare/HDRScreenShare.exe**. Папка `_internal` должна оставаться рядом с EXE.

Для готовой сборки Python устанавливать не нужно. Это переносимая папка, а не установщик.

Для проверки архива сравни результат следующей команды со значением в **SHA256SUMS.txt** из того же релиза:

```powershell
Get-FileHash .\HDRScreenShare-v0.2.4-windows-x64.zip -Algorithm SHA256
```

## Требования

- Windows 11 x64 — платформа, на которой выполнялись проверки.
- HDR-монитор с включённым HDR и настольное приложение Discord.
- Для звука в режиме **Application window** нужен VB-CABLE, устанавливаемый отдельно из оригинального пакета производителя.
- Для режима **Virtual screen** нужен подписанный драйвер виртуального дисплея; его установка доступна через **Devices**.

## Как транслировать

1. Запусти программу. Обработка не начнётся до нажатия **Start**.
2. Выбери исходный HDR-монитор и режим трансляции.
3. Нажми **Start**. В режиме **Virtual screen** подтверди запрос Windows UAC.
4. Открой выбор источника трансляции в Discord, выбери источник, указанный программой, и включи соответствующую передачу звука.

| Режим | Что выбирать в Discord | Экран и права | Звук |
| --- | --- | --- | --- |
| **Application window** | **HDR Screen Share** | Виртуальный монитор не создаётся, UAC не требуется | Отфильтрованный звук приложений через VB-CABLE |
| **Virtual screen** | Номер экрана, показанный программой | Создаётся виртуальный экран; при каждом Start запрашивается UAC | Системный звук средствами Discord |

**Application window** выводит готовое SDR-изображение в отдельное окно за пределами видимой области рабочего стола. Окно отрисовывается через Direct3D и не занимает место на физических мониторах. Драйвер виртуального дисплея для этого режима не нужен.

**Virtual screen** выводит SDR-изображение на выделенный виртуальный экран. При Stop, закрытии или аварийном завершении программы временный помощник отключает адаптер, и виртуальный монитор исчезает из списка экранов Windows. Драйвер остаётся установленным для следующего запуска; постоянная служба не устанавливается. Физические мониторы не дублируются и не перенастраиваются.

## Звук и первичная настройка

Открой **Devices**. Установи только то, что нужно выбранному режиму: драйвер виртуального экрана для **Virtual screen** или VB-CABLE для звука **Application window**. Наушники должны оставаться устройством вывода Windows по умолчанию.

Фильтр исключения Discord действует в режиме **Application window**. В режиме **Virtual screen** захват системного звука выполняет сам Discord. Звук вкладки Discord в браузере нельзя надёжно отделить от других звуков того же браузера — для фильтра используйте настольный Discord. Неподдерживаемые системные аудиосессии исключаются из отфильтрованного микса.

## Миниатюры и статусы

Тумблер **Before / After** по умолчанию выключен. **Before** показывает исходный HDR-сигнал с ограничением яркости для SDR-превью, **After** — обработанное SDR-изображение. Before иллюстрирует отсутствие тонмаппинга и не воспроизводит в точности внутреннюю обработку Discord.

Сравнение не меняет передаваемое изображение. Дополнительный захват для Before работает только при включённом сравнении, с частотой до 5 FPS, и приостанавливается при сворачивании панели управления. Обычная миниатюра обновляется до 15 FPS. Сворачивание панели не останавливает трансляцию.

## Состояние версии

Это предварительная версия. Пройдены 97 автоматических тестов, проверены локальный захват HDR 2560×1440, меняющееся синтетическое 4К-окно, переключение режимов и удаление виртуального экрана.

Получение изображения и звука зрителем Discord, синхронизация аудио/видео и реальная трансляция HDR 4K60 ещё не подтверждены. Указанные разрешение и частота являются пределом вывода и целевой частотой, а не гарантией производительности.

Подробные результаты: [v0.2.4](docs/verification-v024.md), [v0.2.3](docs/verification-v023.md). В обычном режиме программа не сохраняет кадры или звук. Журнал приложения: `%LOCALAPPDATA%/HDRScreenShare/app.log`.

## Сборка из исходников

Нужны CPython 3.12 x64, MSVC x64 Build Tools с компонентами Desktop development with C++ и Windows SDK.

```powershell
py -3.12 -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements-dev.txt
./build.ps1
```

Готовая программа: `dist/HDRScreenShare/HDRScreenShare.exe`. Для запуска из исходников используй `./run.ps1` после сборки нативных модулей.

Архив релиза и контрольная сумма:

```powershell
./scripts/package-release.ps1
```

Результат появится в `dist/releases`. Окружение разработки, сборки, временные файлы и журналы не добавляются в Git.

Автоматические тесты:

```powershell
.venv/Scripts/python.exe -m pytest -q -p no:cacheprovider
```

Нативные проверки из папки `tools` запускаются вручную на рабочем столе Windows; экранные проверки могут запрашивать UAC. Они не включают трансляцию Discord.

## Если что-то не работает

- **Нет изображения:** выбери HDR-монитор, нажми Start и заново открой список источников Discord. Для оконного режима выбирай **HDR Screen Share**, а не панель **Controls**.
- **Нет звука приложения:** проверь VB-CABLE через Devices, оставь наушники устройством вывода по умолчанию и включи звук приложения в Discord.
- **Не запускается виртуальный экран:** установи его подписанный драйвер через Devices и подтверди UAC при Start.
- **Сообщение об ошибке:** укажи версию программы, режим, версию Windows, разрешение и HDR-статус монитора, а также нужные строки журнала. Личные изображения и звук прикладывать не нужно.
