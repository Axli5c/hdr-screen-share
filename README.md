# HDR Screen Share

Небольшая программа для Windows x64: захватывает выбранный монитор, преобразует HDR в SDR и показывает картинку в отдельном окне для трансляции в Discord. HDR у владельца экрана остаётся включённым.

## Запуск готовой программы

1. Откройте `dist/HDRScreenShare/HDRScreenShare.exe`. Сохраняйте рядом папку `_internal`: один exe отдельно работать не будет. Python отдельно устанавливать не нужно.
2. Выберите HDR-монитор, который хотите показывать. По умолчанию выбирается основной HDR-монитор, иначе первый HDR-монитор.
3. Выберите второй монитор для окна-копии. По умолчанию выбирается другой подключённый монитор; автозахват запускается при открытии программы.
4. В Discord выберите **трансляцию приложения «HDR Screen Share — Discord»**. При необходимости включите показ всех приложений в списке источников. Не выбирайте обычную трансляцию исходного HDR-экрана.

Окно-копия открывается без рамки на втором мониторе. Его можно перекрывать другими окнами, но нельзя сворачивать. Управление захватом и закрытие — через основное окно программы. Нужны два монитора: окно целиком за пределами рабочего стола не даёт корректного захвата Windows.

## Разрешение и FPS

- До 3840×2160, для портретной ориентации — до 2160×3840, цель 60 FPS.
- Картинка сохраняет пропорции и не увеличивается сверх размера источника.
- Вывод должен помещаться на втором мониторе. Для полноценного вывода 4K второй монитор также должен иметь подходящее физическое разрешение; иначе интерфейс явно показывает ограничение размера. Ограничение не скрывается.
- В интерфейсе отдельно показаны частота новых захваченных кадров и частота отрисовки окна. Статичный экран может давать меньшие значения. Эти показатели не измеряют FPS у зрителя Discord.
- Доступное разрешение трансляции, частота кадров и качество в Discord проверяются отдельно в самом Discord.

Звук игры эта версия не захватывает и не передаёт. Для игр рекомендуется безрамочный режим; совместимость эксклюзивного полноэкранного режима не гарантируется.

## Сборка из исходников

Нужен CPython 3.12 x64. В PowerShell из папки проекта:

```powershell
py -3.12 -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements-dev.txt
$env:PYTHONPATH = Join-Path (Get-Location) 'src'
.venv/Scripts/python.exe app.py
```

`requirements.txt` загружает готовый Windows wheel hdrcapture из GitHub Releases с проверкой SHA-256. Rust и Visual Studio для этого пути не нужны. Зависимости устанавливаются только в локальную `.venv`.

```powershell
./build.ps1
```

Готовая папка — `dist/HDRScreenShare`. Исходный запуск без консольного окна — `./run.ps1`.

## Проверки и текущий статус

Автоматические проверки: выбор HDR-источника, соответствие экранов по физической геометрии, размеры до 4K, владение памятью, отсутствие очереди кадров, остановка/ошибки и повторный запуск.

Реальный HDR-захват и вывод SDR проверены на двух мониторах 2560×1440. Измерения и ограничения — в `docs/verification.md`. Полноценная проверка 4K/60 и просмотр через второй клиент Discord пока не выполнены; приложение следует считать прототипом до этих проверок.

## Если возникла ошибка

- Подключите второй монитор, нажмите «Обновить» и проверьте выбор обоих экранов.
- После включения/выключения HDR или изменения конфигурации экранов обновите список и перезапустите захват.
- При отсутствии изображения у зрителя убедитесь, что выбрано окно приложения, окно-копия открыто и находится на втором мониторе.
- Диагностика записывается в `%LOCALAPPDATA%/HDRScreenShare/app.log`. Кадры экрана и видео программа в файлы не записывает.
